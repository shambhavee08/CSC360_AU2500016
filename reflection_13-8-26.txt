In this lecture of Computer Graphics and Image Processing, we were introduced to the basic setup required for developing graphics applications using Java and Maven. We learned how to download and install Java and Maven and understood why these tools are important for running and managing a project.
We then created a Maven project and used it to make a simple square. Although creating a square sounds very basic, it helped me understand how a project is structured and how the different tools work together to create a graphical output. Setting up the Maven project was initially a little confusing because there were several steps involved, but once the setup was complete, seeing the square appear as the final output made the process easier to understand.
